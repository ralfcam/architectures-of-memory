# Forbidden Phrases (Living List)

These phrases violate the compositional grammar. Do not use:

- "you should" / "you must" (instructional tone)
- "optimal" / "optimize" (optimization culture)
- "perfect child" / "ideal" (manufacturing narrative)
- "brain-based proof that…" (neuroscience sensationalism)
- "evolutionarily designed to" (evolutionary storytelling detached from evidence)
- "irreversibly harms" / "ruins" / "destroys" (alarmism, determinism)
- "critical window" (unless evidence grade is High and persistence is demonstrated)
- "parental fate" / "destiny" (determinism)
- "science says" (conflates science with interpretation)

If a phrase appears, revise to:
- Calibrate claim strength to evidence grade.
- Use probabilistic language ("is associated with," "may increase").
- Return to the child, not the parent's performance.
