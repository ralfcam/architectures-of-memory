# Master Source Catalog

This catalog aggregates every source currently cited across `evidence-cards/`, serving as the fundamental provenance baseline for the knowledge base. It has two tiers:

1. **Verified resources** - sources with a confirmed, resolvable URL, also declared in this file's OKF frontmatter `sources` array for machine traversal.
2. **Unresolved citations** - sources named in evidence-card bibliographies during the initial literature pass but not yet matched to a verified, stable resource link. These require a follow-up audit pass before being promoted to tier 1.

Per `CONTRIBUTING.md`, no source here has been checked for retraction, replication failure, or predatory-journal status beyond what was visible in the originating search. Treat this catalog itself as **status: draft**.

## Maintenance Rule

Whenever a new evidence card is added or revised (see `CONTRIBUTING.md` and `CHANGELOG.md`), add or update its sources here in the same commit: move any newly verified resource into the Verified Resources table (and mirror it in the frontmatter `sources` array), or add newly cited but unverified works to the Unresolved Citations table. This file, not any individual card, is the single point of truth for "what has this knowledge base actually cited."
