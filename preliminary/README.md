# Preliminary Workbench

This directory is a staging area for materials that will later be integrated into the main knowledge base (`evidence-cards/`, `SOURCES.md`) and manuscript (`chapters/`, `COMPOSITION.md`).

## Subdirectories

- **`research/`** — Raw notes, literature summaries, and work-in-progress evidence syntheses that have not yet been formalized into OKF evidence cards.
- **`drafts-chapters/`** — Chapter drafts and outlines that are still in active composition and have not yet passed the `style/voice-checklist.md` review.

## Workflow

1. Add work here as you develop it locally.
2. When a research note is ready for the KB, convert it to an OKF evidence card in `evidence-cards/` and register its sources in `SOURCES.md`.
3. When a chapter draft is complete, run it through `style/voice-checklist.md`, then move it to `chapters/` and update `CHANGELOG.md`.

Files in `preliminary/` are not expected to conform to OKF frontmatter or compositional-grammar rules until they are promoted.
