# Chapter draft reviews

Keep critique **separate** from draft text. Do not overwrite files in `../` during review.

Use `style/voice-checklist.md` and `style/forbidden-phrases.md` as the instrument. Save one note per chapter:

```text
preliminary/drafts-chapters/reviews/chNN-structural-and-voice-review.md
```

## Questions to answer

- Does it open with a phenomenon or anomaly rather than a conclusion?
- Does it articulate a genuine puzzle?
- Are cases used as entry points rather than evidence substitutes?
- Are competing explanations presented before resolution?
- Is Science / Interpretation / Art visible when needed?
- Does it state what evidence does **not** establish?
- Does it reconnect the focal phenomenon to wider systems?
- Does it end by returning to the child?
- Does it avoid optimization, deterministic, alarmist, and parent-blaming language?

## Promotion rule

A draft moves to `chapters/` only after:

1. Linked evidence cards have been audited (`status` no longer a first-pass draft; frontmatter confidence assigned; `SOURCES.md` updated).
2. This review is complete and remaining voice failures are fixed in a **new** curated draft, not by silently rewriting the archival original.
