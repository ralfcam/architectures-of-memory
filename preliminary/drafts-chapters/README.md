# Preliminary Chapter Drafts

This subdirectory holds chapter drafts and outlines that are still in active composition and have not yet passed the `../../style/voice-checklist.md` review.

## Purpose

- Draft freely without worrying about perfect voice or evidence calibration.
- Experiment with anomalies, cases, and systems mappings before locking in a chapter structure.

## When Ready

Once a draft is sufficiently developed:
1. Run it through `../../style/voice-checklist.md` and save the review in `reviews/` rather than overwriting this file.
2. Move a **curated copy** to `../../chapters/` (or merge into an existing chapter outline) only after linked evidence cards are audited.
3. Update `../../CHANGELOG.md` to log the addition or revision.

Keep these files as archival drafts. Future curated copies use `chNN-title--draft-NN.md`.
