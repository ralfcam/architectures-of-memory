This note covers every live card as of the 36-card catalog, then the two Chapter 7 cards added in the same package. Genetically informed (GI) attenuation uses CONTRIBUTING’s bins: **largely confounded (>50%)**, **partially confounded (20–50%)**, **robust (<20%)**. Where that design class does not exist, the cell is `n/a`.

## Decision rule (unchanged)

A card may move to `stable` only after:

1. Sources remain resolvable.
2. No retraction or expression-of-concern for the primary ID.
3. Replication or GI attenuation has been classified where that design class exists.
4. In-body grade still matches YAML `confidence`.
5. “What This Does Not Mean” still matches the identification.

This pass completes (3) catalog-wide. Rules (1)–(2) were addressed in earlier DOI/retraction dumps. **Three narrow physiology/lab claims later cleared all five** (`stable-candidates--replication-note.md`).
